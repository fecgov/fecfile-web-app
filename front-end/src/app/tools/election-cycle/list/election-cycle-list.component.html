Election cycles

About election cycles

To create and file a Form 3, you'll need to provide the dates of the election cycle. An election cycle begins the day after the previous general election for a given federal office and ends on the date of the general election for that office.

For current and future election cycle dates, visit the "Election cycle and aggregation" page on FEC.gov. For information on special election dates, visit "Dates and deadlines".

How to edit election cycle dates

If your election cycle dates change due to the candidate running in a general runoff election, or for a different office, you should edit the end date for the election cycle. Keep in mind that election cycles cannot overlap, so if you’ve already created future cycles, you may need to update those cycles as well to reflect the new dates.


Special elections: If the candidate runs in a special election after you already created the general election cycle, you may need to adjust the start date of the existing general election cycle and then create a new special election cycle so the two cycles do not overlap. Alternatively, you may convert the existing general election cycle by changing the type to Special, editing the end date, and creating a new general election cycle to cover the remaining period.
